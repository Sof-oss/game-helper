Формулы

Граната = round(55 × 1.02^уровень) + шмот + таланты Гранатомёт = round(113 × 1.02^уровень) + шмот + таланты Гаусс = round(360 × 1.02^уровень) + шмот + таланты Нож = floor(45.85 + 1.15 × уровень) + шмот Пистолет = floor(47.8 + 1.2 × уровень) + шмот Автомат = floor(53.65 + 1.35 × уровень) + шмот

Формула Гаусса обновлена: базовое значение — 360.
