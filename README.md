# Game Helper

Сайт-помощник для игроков MMO по мотивам вселенной S.T.A.L.K.E.R.

## Сейчас

Первая версия содержит калькулятор урона: граната, гранатомёт, Гаусс, бесплатные удары ножом/пистолетом/автоматом, выбор комплектов и одиночных вещей, а также бонусы критического удара.

## GitHub Pages

Проект полностью статический и публикуется через GitHub Actions.

## Данные

Списки комплектов и одиночных вещей находятся в `app.js` в массивах `SETS` и `ITEMS`.

## Формулы

Калькулятор использует следующие формулы:

- Граната: `round(55 * 1.02^уровень) + бонусы от вещей + бонусы талантов`
- Гранатомёт: `round(113 * 1.02^уровень) + бонусы от вещей + бонусы талантов`
- Гаусс: `round(360 * 1.02^уровень) + бонусы от вещей + бонусы талантов`
- Нож: `floor(45.85 + 1.15 * уровень) + бонусы от вещей + бонусы талантов`
- Пистолет: `floor(47.8 + 1.2 * уровень) + бонусы от вещей + бонусы талантов`
- Автомат: `floor(53.65 + 1.35 * уровень) + бонусы от вещей + бонусы талантов`
