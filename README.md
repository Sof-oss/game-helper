# Game Helper

Сайт с полезностями для онлайн-игры «Сердце зоны».

## Сейчас

**Калькулятор урона**
- Оружие за жетоны: граната, подствольный гранатомёт, гаусс-пушка — база, бонусы от экипировки, бонусы от талантов, шанс и урон крита.
- Бесплатные удары по боссам: нож, пистолет, автомат — база, бонусы от экипировки, бонусы от талантов.
- Дополнительные характеристики: шанс удара без отката, сокращение отката, бонус урона первого бесплатного удара.
- Выбор комплектов и одиночных вещей снаряжения, кнопка «Выбрать всё», сброс с подтверждением.

**Дерево талантов**
- Две ветки: «Боевая подготовка» (бесплатные удары) и «Арсенал» (платные удары).
- Прокачка/откат ранга по узлу с проверкой зависимостей.
- Тултип при наведении на узел — название, ранг, эффекты по рангам.
- Подсветка пути требований от выбранного таланта до корня ветки.
- Pinch-zoom и панорамирование дерева (тач на мобильных, drag мышью и Ctrl+колесо на десктопе).
- Прогресс сохраняется в `localStorage`.
