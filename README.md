# Game Helper

Сайт-помощник для игроков MMO по мотивам вселенной S.T.A.L.K.E.R.

## Сейчас

Первая версия содержит калькулятор урона: граната, гранатомёт, Гаусс, бесплатные удары ножом/пистолетом/автоматом, выбор комплектов и одиночных вещей, а также бонусы критического удара.

## GitHub Pages

Проект полностью статический и публикуется через GitHub Actions.

## Данные

Списки комплектов и одиночных вещей находятся в `app.js` в массивах `SETS` и `ITEMS`.

## Формулы

Калькулятор использует формулы из задания пользователя. Для Гаусса используется базовое значение 340:

`round(340 * 1.02^уровень) + бонусы от вещей + бонусы талантов`.

В исходном Excel-файле в строке Гаусса указано 360; это расхождение отмечено на странице калькулятора и в коде приоритет отдан формуле из задания.
